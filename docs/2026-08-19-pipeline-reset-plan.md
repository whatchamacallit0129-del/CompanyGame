# 2026-08-19 개발 파이프라인 전면 재설계 계획

## 기록 시각
2026-08-19

## 내일의 핵심 결정
현재까지 만든 **CommandAgent 중심 개발 파이프라인을 유지하지 않고 전면 재검토한다.**

게임 기획 자체를 버리는 것이 아니다. 지금까지 정리한 CompanyGame의 게임 방향과 로드맵은 유지하고, **개발을 실행하는 기술적 파이프라인을 더 단순하고 안정적인 구조로 다시 설계한다.**

## 왜 갈아엎는가

현재 구조는 대략 다음과 같다.

`ChatGPT → Rerun → Chrome → CommandAgent → Unity → result/error → GitHub → ChatGPT`

실제 작업에서 다음 문제가 반복되었다.

- CommandAgent가 개발 과정에 불필요한 중간 계층이 됨.
- command.json 등의 파일 전달 과정에서 파일 잠금/동기화 문제가 발생함.
- Rerun이 ChatGPT에 자동으로 메시지를 입력/전송하고 응답을 감지하는 과정이 안정적으로 작동하지 않음.
- 사용자가 직접 CONTINUE를 눌러야 다음 작업이 진행되는 상황이 반복됨.
- Unity의 실제 컴파일/실행 결과가 자동화 흐름에 안정적으로 연결되지 않음.
- 자동화 시스템 자체를 수정하는 데 시간이 많이 들어 게임 개발이 늦어짐.

따라서 **CommandAgent를 고치는 것을 목표로 삼지 않는다.** 먼저 CommandAgent 없이도 개발과 검증이 가능한 구조를 만든다.

## 내일 우선 검토할 목표 구조

`ChatGPT → GitHub → Unity 자동 컴파일/테스트 → result/error → GitHub → ChatGPT`

가능하다면 GitHub Actions를 이용해 Unity 컴파일 및 테스트를 자동화하는 방안을 검토한다.

Rerun은 게임 개발의 중심이 아니라 **작업 반복을 관리하는 선택적 Controller**로 분리한다.

## 중요한 설계 원칙

### 1. ChatGPT가 GitHub에서 직접 개발

ChatGPT가 저장소의 코드를 직접 읽고 수정할 수 있는 부분은 CommandAgent를 거치지 않는다.

- 코드 검색
- 코드 작성/수정
- 테스트 코드 작성
- 결과 분석
- 오류 수정
- 변경사항 확인

을 GitHub 중심으로 수행한다.

### 2. Unity는 실제 실행/검증 담당

Unity 내부에 ChatGPT 명령을 해석하는 거대한 CommandAgent를 두지 않는다.

Unity는 가능한 한 단순하게:

- 프로젝트 컴파일
- 자동 테스트 실행
- 실제 게임 시스템 검증
- result.json 생성
- error.json 생성

을 담당한다.

### 3. 게임 코드와 자동화 코드를 분리

게임 코드가 Rerun, CommandAgent, command.json 등에 직접 의존하지 않도록 한다.

자동화 시스템을 나중에 완전히 교체하거나 삭제해도 게임 코드가 영향을 받지 않아야 한다.

### 4. 자동화는 확장 가능한 계층으로 설계

ChatGPT 통신 방식, Unity 실행 방식, 결과 수집 방식을 하나의 구현에 하드코딩하지 않는다.

향후 필요하면 Browser/API/Local 등의 통신 방식을 교체할 수 있는 구조를 검토한다.

### 5. 실제 완료 판정은 테스트 결과 기준

ChatGPT가 '완료했다'고 말하는 것만으로 COMPLETE 처리하지 않는다.

실제 acceptance criteria를 Unity에서 검증하고 결과가 성공한 경우에만 완료로 판단한다.

10. 게임 코드 자체는 필요 이상으로 다시 작성하지 않고, 파이프라인부터 안정화

## 게임 개발 측면의 기존 방향은 유지

다음 게임 목표는 유지한다.

- 2D 횡스크롤 회사 경영 게임
- 로보토미 코퍼레이션과 유사한 직원 조작감
- Node/Corridor 기반 직원 이동
- 생산라인이 점점 복잡해지는 공장형 구조
- 직원/시설/생산/회사 경영 시스템
- 하루 단위 진행과 종료
- 정책 및 이벤트
- 정상적인 회사처럼 시작해서 점차 어두운 진실이 드러나는 세계관
- 인간에게서 추출하는 물질과 그 부산물
- 소수의 희생으로 다수의 이익을 실현할 수 있는가라는 핵심 윤리적 테마
