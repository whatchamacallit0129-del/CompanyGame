# CompanyGame — 1일차 개발 추가 기록

> 오늘 기획 과정에서 발전한 아이디어를 기록한다. 아직 확정되지 않은 세부 설정은 **아이디어/검토 사항**으로 분리한다.

## 1. 핵심 개발 방향의 발전

기존의 '접객 회사'라는 초기 아이디어에서 벗어나, 플레이어가 **회사의 특정 부서를 관리하는 관리직**으로서 생산/가공 공정을 운영하는 방향으로 발전했다.

핵심은 플레이어가 처음부터 모든 과정을 직접 보지 못하고, 회사의 구조와 생산라인을 운영하면서 점차 숨겨진 과정을 이해하게 만드는 것이다.

```text
[관리직으로 시작]
        │
        ▼
[제한된 구역과 공정 관리]
        │
        ▼
[생산라인 확장]
        │
        ▼
[새로운 구역 해금]
        │
        ▼
[회사 내부 구조 이해]
        │
        ▼
[숨겨진 생산 과정에 대한 의문]
```

## 2. 생산라인과 정보 공개 방식

게임의 생산라인은 공장형 구조를 갖는다. 플레이어가 관리하는 구역을 중심으로 생산/가공 과정이 연결되며, 공정이 진행될수록 회사의 내부 구조가 복잡해진다.

특히 **원료가 들어오는 지점과 실제 원료가 만들어지는 과정 사이에 정보의 단절**을 두는 방향을 검토한다.

```text
[원료 공급]
     │
     ▼
[파이프/공급관]
     │
     ▼
[플레이어가 관리하는 공정]
     │
     ▼
[가공/정제]
     │
     ▼
[최종 생산물]
```

초기에는 플레이어에게 실제 추출 과정을 직접 보여주지 않고, **특정 파이프를 통해 원료가 공급되는 모습**만 보여주는 방식이 가능하다.

이 구조는 후반부에 실제 추출 과정이 밝혀지는 서사적 반전과 연결할 수 있다.

## 3. 추출 과정에 대한 아이디어

현재 검토 중인 방향은 인간에게서 물질을 직접 추출하는 과정을 플레이어의 시야 밖에 두는 것이다.

가능한 원료 제공 대상의 예:

- 사망자의 시신
- 사형수
- 자원자

단, 위 대상과 구체적인 처리 방식은 **아직 확정된 설정이 아니다.** 게임의 중심 주제와 생산 시스템을 구체화하면서 결정한다.

핵심은 특정 대상 자체보다 다음 구조에 있다.

```text
[사람에게서 추출]
        │
        ▼
[플레이어에게 직접 공개되지 않는 추출 과정]
        │
        ▼
[파이프를 통한 원료 공급]
        │
        ▼
[플레이어가 관리하는 생산 공정]
        │
        ▼
[인류의 사고를 돕는 물질]
```

## 4. 정보의 단계적 공개

플레이어가 처음부터 회사의 전체 진실을 알지 못하도록 한다.

```text
[초기]
  │
  ├─ 원료의 정체를 명확히 알 수 없음
  ├─ 공급관/파이프를 통해 원료가 들어옴
  └─ 생산 공정과 결과물 중심으로 이해
  │
  ▼
[중반]
  │
  ├─ 원료의 이상한 특징 발견
  ├─ 회사의 기록/공정/시설을 통해 단서 획득
  └─ 원료와 인간의 관계를 의심
  │
  ▼
[후반]
  │
  └─ 숨겨진 추출 과정과 그 실체를 확인
```

이 구조의 목적은 플레이어에게 단순히 '회사는 나쁜 일을 하고 있다'고 알려주는 것이 아니라, **플레이어가 회사의 운영을 직접 수행하면서 점차 진실을 이해하도록 하는 것**이다.

## 5. 윤리적 딜레마와 시스템의 연결

추출 대상의 종류와 사회적 지위가 달라질 경우 플레이어가 서로 다른 방식으로 이를 정당화할 수 있다.

예를 들어 향후 다음과 같은 상황을 고려할 수 있다.

```text
[자원자]
   │
   ▼
"본인의 동의가 있다."

[사형수]
   │
   ▼
"법적으로 처벌받은 사람이다."

[사망자]
   │
   ▼
"이미 사망한 사람이다."

       ↓

[그렇다면 사회 전체의 이익을 위해 사용해도 되는가?]
```

이것은 아직 구체적인 게임 이벤트로 확정하지 않는다. 핵심은 **플레이어가 스스로 회사의 행위를 합리화하거나 의심하게 만드는 구조**를 구축하는 것이다.

## 6. '숨겨진 추출실' 아이디어

추출실은 게임 초반부터 플레이어가 직접 볼 수 있는 장소가 아니라, 생산라인의 뒤편 또는 별도의 잠긴 구역으로 둘 수 있다.

```text
                 [관리 구역]
                      │
                      ▼
                [원료 공급관]
                      │
                      ▼
               ┌───────────┐
               │ 플레이어가 │
               │ 관리하는   │
               │ 생산 공정  │
               └─────┬─────┘
                     │
                     ▼
                 [가공/정제]
                     │
                     ▼
                 [최종 생산물]

             ─ ─ ─ 정보의 장벽 ─ ─ ─

                  [추출실]
                     │
                  [???]
```

후반에 구역이 해금되면서 추출실에 접근할 수 있게 만들면, **플레이어가 이전까지 당연하게 받아들였던 생산라인의 의미가 바뀌는 순간**을 만들 수 있다.

## 7. 반전 설계의 핵심 원칙

반전의 목표는 '회사가 사실 악당이었다'라는 단순한 반전이 아니다.

```text
[플레이어는 생산을 효율적으로 운영한다]
              │
              ▼
[생산량이 증가한다]
              │
              ▼
[회사가 성장한다]
              │
              ▼
[생산량 증가에 따라 더 많은 원료가 필요하다]
              │
              ▼
[원료의 정체를 의심하기 시작한다]
              │
              ▼
[숨겨진 추출 과정 발견]
              │
              ▼
[지금까지 자신이 운영한 생산라인의 의미를 재해석]
```

따라서 반전은 스토리 컷신 하나로 끝나는 것이 아니라, **플레이어가 이전에 직접 수행했던 게임플레이를 다시 생각하게 만드는 방식**을 목표로 한다.

## 8. 개발상 중요한 원칙

- 생산라인 자체가 재미있어야 한다.
- 숨겨진 진실이 밝혀지기 전에도 게임플레이가 성립해야 한다.
- 플레이어에게 모든 정보를 한꺼번에 제공하지 않는다.
- 회사의 행위를 게임이 직접 '정답/오답'으로 판정하기보다 플레이어가 판단할 여지를 남긴다.
- 반전은 단순한 설정 공개가 아니라 기존 게임 시스템의 의미를 바꾸는 방식으로 설계한다.
- 아직 확정되지 않은 대상, 시설명, 추출 방법 등은 개발 과정에서 검토한다.
