# CompanyGame — 1일차 게임 기획 플로우차트

> **Day 1 / 1일차 기록**
>
> 이 문서는 1일차에 확정된 내용만 기록한다. 접객, 손님 등 아직 구체적으로 결정되지 않은 요소는 포함하지 않는다.

## 1. 프로젝트 방향

```text
[2D 회사 경영 시뮬레이터]
          │
          ▼
[클릭 & 드래그 중심의 조작]
          │
          ▼
[공장형 생산/가공 라인]
          │
          ▼
[회사의 공정과 구역을 관리]
          │
          ▼
[시간 경과에 따라 새로운 구역/공정 해금]
```

## 2. 플레이어의 역할

```text
[회사 특정 부서의 관리직으로 시작]
          │
          ▼
[담당 구역과 공정 관리]
          │
          ▼
[공정 배치 및 운영]
          │
          ▼
[회사의 성장]
          │
          ▼
[시간이 지날수록 더 많은 구역과 공정 해금]
```

## 3. 핵심 게임 루프

```text
        ┌─────────────────────┐
        │     회사 운영       │
        └─────────┬───────────┘
                  ▼
        [물질 추출 및 확보]
                  │
                  ▼
        [특수 공정을 통한 가공]
                  │
                  ▼
        [인류의 사고를 돕는 물질 생산]
                  │
                  ▼
        [생산/관리 효율 향상]
                  │
                  ▼
        [새로운 구역 및 공정 해금]
                  │
                  └───────────────┐
                                  │
                                  ▼
                           [회사 운영 강화]
```

## 4. 세계관의 핵심 기술

```text
[인간에게 윤리적으로 중요한 무언가]
                  │
                  ▼
              [갈취/추출]
                  │
                  ▼
          [특별한 공정으로 가공]
                  │
                  ▼
       [인류의 사고를 돕는 물질]
```

- 회사는 인간에게서 윤리적으로 중요한 무언가를 갈취/추출할 수 있는 특별한 기술을 보유한다.
- 추출된 것을 특별한 공정을 통해 가공하여 인류의 사고를 돕는 물질을 생산한다.
- 이 기술과 생산 과정이 회사의 핵심적인 존재 이유이자 게임 플레이의 중심이다.

## 5. 게임 진행 구조

```text
[초기]
  │
  ├─ 제한된 구역
  ├─ 제한된 공정
  └─ 제한된 관리 범위
  │
  ▼
[운영 및 성장]
  │
  ├─ 생산/가공 공정 확장
  ├─ 관리해야 할 요소 증가
  └─ 새로운 구역 해금
  │
  ▼
[후반]
  │
  ├─ 복잡해진 생산라인
  ├─ 확장된 회사 시설
  └─ 플레이어가 회사 전체 구조를 이해하게 됨
```

## 6. 핵심 주제

### 중심 질문

> **소수의 가치를 갈취하여 다수의 이익을 실현하는 일은 정당화될 수 있는가?**

```text
[소수에게 발생하는 피해]
          │
          ▼
[인간의 가치 일부를 갈취]
          │
          ▼
[회사의 생산 활동]
          │
          ▼
[다수에게 이익이 되는 결과]
          │
          ▼
[그 이익을 위해 발생한 피해는 정당화될 수 있는가?]
```

## 7. 플레이어 경험의 방향

```text
[회사 관리의 재미]
        +
[생산라인을 직접 구성하고 확장하는 재미]
        +
[점차 복잡해지는 회사 구조를 관찰하는 재미]
        +
[세계관과 설정이 진행에 따라 밝혀지는 경험]
        +
[회사의 행위에 대한 윤리적 딜레마]
        │
        ▼
[플레이어 스스로 회사의 행위와 결과를 판단]
```

## 11. 아직 확정하지 않은 것

아래 요소들은 현재 문서에서 의도적으로 제외한다.

- 플레이어가 구체적으로 누구를 어떻게 상대하는지
- 손님/접객 시스템의 구체적인 형태
- 피해 대상의 구체적인 설정
- 추출되는 물질의 구체적인 이름과 세부 설정
- 생산 공정의 세부 단계
- 자원/화폐의 구체적인 구조
- 직원의 세부 능력 및 AI
- 정부/외부 세력의 구체적인 등장 방식
- 스토리의 세부 전개

> 위 요소들은 추후 게임 시스템과 세계관을 구체화하면서 별도의 기획 문서로 확정한다.
